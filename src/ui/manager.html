      Settings

      Scripts folder

      Pick a dedicated folder — scripts are written there as .ts files and every edit (from either side) syncs instantly.

      Absolute folder path — used by the ↗ VS Code button (the browser can't read the real path itself).

      Import / Export

      Export all scripts to a YAML bundle, or import scripts from a bundle (.yaml/.yml/.json) or a single .ts/.js file.

      Local helper (strategy "process")

      Scripts listing process in their strategy are intercepted by rescript-helper, a small local proxy — no debugger banner, every resource type, Chrome only. Your own proxy setting stays in effect for everything else.
