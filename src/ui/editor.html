      Synced folder

      Folder

      Scripts are written there as .ts files; every edit, from either side, syncs instantly.

      Absolute path of that folder, used by the ↗ VS Code button — the browser can't read it, so paste it in.

      What the ↗ button in the editor toolbar launches.

      {path} is the file's absolute path, {line} the cursor line. E.g. cursor://file{path}:{line}, zed://file{path}:{line}, idea://open?file={path}&line={line}, subl://open?url=file://{path}&line={line}.

      Import / Export

      Bundle

      Export any subset of scripts (and the global settings) to a YAML bundle. Import a bundle (.yaml/.yml), picking which of its items to take, or a single .ts/.js file.

      Strategy

      Default strategy

      Pick a row. How handlers intercept traffic unless their route sets strategy. A handler whose strategy isn't available doesn't run — it gets a ⚠ and a Log view warning; there is no fallback. Compatibility

      Local helper

      Status
      … 
      
                                
      Handlers using the helper strategy are intercepted by wiretrick-helper, a small local proxy — no debugger banner, every resource type, Chrome only. More robust than page, which only sees the page's own fetch/XHR calls. Your own proxy setting stays in effect for everything else.
